# Multiplayer Base

Multiplayer mode has now been created as a separate copy of the normal mode.

- `script.js` = normal mode
- `multiplayer-mode.js` = copied normal gameplay used by multiplayer
- `multiplayer.html` = multiplayer entry page

At this stage multiplayer has the same gameplay code as normal mode.
Networking, player synchronization, rooms/matchmaking, and multiplayer-specific
rules have NOT been added yet.
